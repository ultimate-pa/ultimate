Referee

Referee is a deductive verifier. This means that we check whether a program annotated with invariants has invariants sufficient for an inductive proof. For example, for a loop invariant we check if it holds at the beginning of the loop, if it is preserved by the loop body and if it is strong enough to prove the remaining program after the loop is correct. These annotated invariants can be extracted from correctness witnesses, after which Referee can be used as a validator for these.
